# 🎮 Tic Tac Toe Game (Python)

A desktop-based Tic Tac Toe game developed using Python and Tkinter. The application provides an interactive GUI where users can play against another player or compete against the computer.

## ✨ Features

- Two Player Mode
- Player vs Computer Mode
- Interactive graphical user interface
- Random computer moves
- Automatic winner detection
- Draw detection
- Restart game functionality
- Full-screen gameplay
- Welcome and goodbye popups

## 🛠️ Technologies Used

- Python 3
- Tkinter – GUI development
- Random – Computer move generation

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Tic-Tac-Toe-Game.git
```

### 2. Navigate to the project directory

```bash
cd Tic-Tac-Toe-Game
```

### 3. Run the application

```bash
python tic_tac_toe.py
```

## 🎯 Game Modes

**1. Two Player Mode:** Two players take turns using X and O.

**2. Play vs Computer:** Play against the computer, which selects available cells randomly.
